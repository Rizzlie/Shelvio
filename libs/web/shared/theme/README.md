# web-shared-theme

`@shelvio/web/shared/theme` (`scope:web`, `type:util`): the light/dark mode and the theme's runtime half. The palettes, fonts and tokens are in `apps/web/src/styles.scss`.

## Mode

`ThemeModeStore` (NgRx SignalStore, root) holds `mode()`: `'light'`, `'dark'` or `'system'` (Jasny / Ciemny / Systemowy), default `'system'`. `select(mode)` sets `data-theme-mode` on `<html>` and stores the choice in `localStorage` under `shelvio.themeMode`. When storage is blocked, the store starts on Systemowy and switching still works for the visit. `styles.scss` maps the attribute to `color-scheme`, which every `light-dark()` token follows.

An inline script in `apps/web/src/index.html` applies the stored mode before the first paint, so public screens don't flash the other mode while Angular loads. It repeats the storage key and the attribute name; `apps/web/src/index.spec.ts` runs it against `themeModeStorageKey` and `themeModeAttribute` to keep them in step.

The control is `ThemeSwitch` in `@shelvio/web/shared/ui`; bind it with `<app-theme-switch [mode]="store.mode()" (modeChange)="store.select($event)" />`.

## `provideTheme()`

Add it to the app config. It makes `<mat-icon>` draw Material Symbols Outlined (loaded from Google Fonts in `index.html`).

## Styles

- Palettes in `apps/web/src/_theme-colors.scss` are generated by `nx g @angular/material:theme-color` from the theme-decision seeds (primary `#1b432c`, tertiary/brass `#c47a2b`, error/terracotta `#8c4a43`, neutral `#68645e`, neutral variant `#e4e0d7`). Regenerate them rather than editing by hand.
- `mat.theme()` emits every color as `light-dark()`. Only the surface, background and text-on-surface tokens are overridden, with the exact paper and warm-charcoal values.
- Roles: brass is `tertiary` (rating stars), terracotta is `error` (destructive actions), and `--shelvio-warning` is amber for soft warnings.
- Newsreader is used for display and headline roles, Plus Jakarta Sans for title, body and label. Both are self-hosted from `@fontsource` (latin and latin-ext).
- Focus rings: Material's strong focus indicators, plus an outline on `:focus-visible` for everything else.
